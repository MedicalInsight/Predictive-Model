breast cancer prognostic model

Building a predictive model for breast cancer prognostic model using R.

在本案例中，我们基于乳腺癌患者的临床与病理数据，构建并评估多个预后模型。

一、数据预处理

导入乳腺癌患者数据，并剔除存在共线性的变量。随后将数据集随机划分为训练集和测试集（比例约为3000:1607），确保两组数据互不重叠。

二、探索性数据分析

原始数据分布检查

对全量数据做概览检查，包括摘要统计与缺失值分布，以便确定需处理的变量。

对数转换右偏变量

针对 Tumor.Size 和 Regional.Node.Examined 两个右偏变量进行对数转换，以缓解偏态对分析的影响，并再次检验转换后数据分布。将转换后的数据按相同索引划分训练集与测试集。

基线特征

合并训练集和测试集，绘制基线特征对比表（Table 1），便于评估样本划分的均衡性。

检查连续变量与结局之间的线性关系：样条曲线分析

分别绘制 Age、log_Tumor.Size 和 log_Regional.Node.Examined 与生存结局之间的样条关系，探讨是否具有线性趋势。横轴为变量值，纵轴为风险或死亡概率，随时间变化。

三、构建LASSO Cox 回归模型

本节基于训练集数据，使用LASSO方法进行变量筛选和Cox比例风险模型构建，用于预后预测。

构造模型矩阵并进行交叉验证

  • 将字符型变量转换为因子并生成虚拟变量，构造X矩阵和Surv对象（结局变量）。

  • 利用 LASSO Cox 回归（glmnet）在训练集上进行交叉验证以选出最优惩罚参数 λ，并根据两种 λ 值拟合最终模型，输出系数。

四、LASSO模型解释性分析（SHAP 值分析）

由于Cox模型不直接预测生存时间或事件发生的概率，我们对 LASSO Cox 模型进行 SHAP 值分析，来估计变量对模型输出的解释强度和方向。

SHAP分析及可视化

五、构建随机生存森林 (RSF) 模型

本节使用 randomForestSRC 包构建非参数的随机生存森林模型，对比 LASSO 模型的表现，并进行解释性分析。

准备与LASSO模型相同的输入数据，拟合生存随机森林，并可视化变量重要性。

六、RSF模型的SHAP summary

使用SHAP对RSF模型进行解释，与LASSO模型进行对比，分析变量对预测结果的影响。

七、外部验证（测试集验证）

模型在训练集拟合完成后，应当在独立的测试集上进行外部验证，以评估泛化性能。本节开始准备测试集数据，并将其应用于验证阶段。

对测试集进行同样的虚拟变量转换，计算 LASSO-Cox 和 RSF 模型在不同时间点的时间依赖 ROC 曲线（AUC）和 Brier score，并分别绘图和输出 AUC 值。
